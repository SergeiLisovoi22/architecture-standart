### **Название задачи:** Передача ставок в кол-центр (MVP)

### **Автор:** Команда архитектуры / продукт-менеджер

### **Дата:** 2025-10-29

### **Функциональные требования**

- Система кол-центра получает доступ к ставкам по депозитам через интеграцию с внутренней системой банка
- Система кол-центра получает актуальные ставки в виде файла по SFTP-протоколу


| **№** | **Действующие лица или системы**                | **Use Case**                                 | **Описание**                                                 |
|:-----:|:------------------------------------------------|:---------------------------------------------|:-------------------------------------------------------------|
|  UC1  | Менеджер кол-центра, Система кол-центра         | Просмотр актуальных ставок по депозитам      | Менеджер видит актуальный список депозитов                   |
|  UC2  | Система кол-центра, Система кол-центра партнера | Получение файла со ставками                  | Ежедневно система получает файл по протоколу SFTP            |
|  UC3  | Менеджер бэк-офиса                              | Обновление ставок                            | Менеджер редактирует ставку для клиента через единую систему |
|  UC4  | Система кол-центра партнера                     | Подключение к работе партнёрского кол-центра | Если кол-центр банка будет перегружен                        |


### **Нефункциональные требования**

| **№** | **Требование**                                 |
|:-----:|:-----------------------------------------------|
| NFR1  | Данные поступают по защищенному протоколу SFTP |
| NFR2  | Файл для кол-центра генерируется автоматически |


### **Решение**

Приложены диаграммы:

- `C4-Context-Task4.md` — контекстная диаграмма
- `C4-Containers-Task4.md` — диаграмма контейнеров

**Логика решения:**

 - Важно централизовать ставки, чтобы они распределялись во внутренний и внешний кол-центры
 - Файл генерируется автоматически раз в сутки

### **Альтернативы**

 - Отправка данных партнерскому кол-центру через API
 - Оператор бэк-офиса вручную отправляет файлы операторам кол-центра

**Недостатки, ограничения, риски**

 - Обновление ставок раз в день
 - Нет возможности сделать API-вызовы

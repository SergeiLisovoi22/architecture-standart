
# Задачи по системам (Task4 — Передача депозитных ставок)

## Сервис ставок (новый)
- Проектирование схемы БД (история ставок, валидность, архив)
- Функция загрузки ставок из АБС (ETL/процедуры)
- REST API /rates для внутренних систем (CC/IB)
- Экспорт CSV/XLSX для партнёрского КЦ
- Мониторинг ошибок загрузки и публикации

## АБС
- Подготовка выгрузки ставок по регламенту
- Ответственные роли и время цикла обновления ставок

## Система кол-центра (банк)
- Вывод блока ставок в UI операторов
- Интеграция с Rates API
- Обработка недоступности сервиса ставок (кэш/таймаут)

## Партнёрский кол-центр
- Приём и загрузка файлов ставок
- Согласование формата, тестовая загрузка
- UAT с пилотной группой

## Интернет-банк
- Использование ставок из сервиса ставок
- Актуализация витрины депозитов

## Инфраструктура / ИБ безопасность
- Деплой сервиса ставок с балансировкой (горизонтальное масштабирование)
- SFTP/PGP канал с партнёром
- Мониторинг и логирование для аудита
